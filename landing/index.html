Dashboards com Streamlit

Um livro-tutorial em 18 capítulos sobre as principais funções do Streamlit — do pip install ao dashboard publicado. Cada capítulo traz explicação, código copiável, um app executável, questões para reflexão e um quiz de autoavaliação.
